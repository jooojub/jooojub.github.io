Efficiently Transfer Docker Images over SSH without a Registry

Docker 이미지를 별도 Registry 없이 ssh 만으로 옮길 수 있습니다.

Principle

Docker 이미지는 파일 형태로 저장하고 다시 불러올 수 있습니다. 보통은 다음과 같이 두 단계로 진행합니다.
  • Source : docker save로 이미지를 tar 파일로 추출
  • Destination : 파일을 복사한 뒤 docker load로 이미지 등록

Command

ssh의 compress 옵션과 pipeline을 이용하면 좀 더 빠르고 간결하게 전송 가능합니다.
