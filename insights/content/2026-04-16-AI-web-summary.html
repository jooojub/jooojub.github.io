Claude Code Used to Find Remotely Exploitable Linux Kernel Vulnerability Hidden for 23 Years

2026-04-15

Summary

Anthropic 연구원이 Claude Code를 사용하여 23년간 숨겨져 있던 Linux 커널의 원격 코드 실행 취약점을 발견한 사례에 대한 내용.

Key Points

  • Anthropic 연구원 Nicholas Carlini는 Claude Code를 활용해 Linux 커널에서 여러 원격 코드 실행 취약점을 발견했다.
  • 특히 NFS 드라이버에서 2003년부터 존재했던 힙 버퍼 오버플로우 취약점을 찾아냈다.
  • Claude Code는 복잡한 프로토콜 세부 사항에 대한 이해 없이 간단한 스크립트만으로 취약점을 발견했다.
  • 취약점은 112바이트 버퍼에 1056바이트의 데이터를 쓰는 방식으로, 공격자가 커널 메모리를 제어할 수 있게 한다.
  • 이 버그는 Git보다 오래된 2003년 커밋에서 도입되었다.
